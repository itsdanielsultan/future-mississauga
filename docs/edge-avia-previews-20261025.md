# Edge / Oro / Avia previews

Adds only the five approved building studies: Edge 1, Edge 2, Oro, Avia 1 and Avia 2. Oro shows the intended July 2020 design, not current construction progress. Each Avia view combines one exact tower export with its exact shared podium; the other tower is omitted and the shared component is not counted as another building. The download labels explain that two files reproduce each Avia preview.

Architectural credits are supported by the developer's published sources: Roy Varacalli and Cusimano Architect / Solmar for Edge-Oro; Turner Fleischer Architects Inc. / Amacon for Avia. Source photographs, Google pixels, native recovery scenes and unrelated studies are not redistributed. City terms precede Avia loading and downloads; Edge/Oro contain no retained municipal mesh. Approximate dimensions, source dates, hidden details and separate architectural rights remain explicit.

## Rendering and mobile behavior

Only the selected study loads, sequentially when it has two components. Both compressed and decoded hashes are checked before parsing. Failure and integrity rejection retain retry controls. City-derived models do not request geometry before the visitor's load/download action.

For these six reviewed static assets, the display batches opaque surfaces sharing materials and compatible attributes. Transparent geometry keeps its original meshes and sorting. Geometry groups, reflections, animation/deformation, visibility and rendering layers are respected. Source files and download buffers are unchanged. Three.js normal normalization introduces at most 5.96e-8 component differences in display copies; source arrays remain byte-identical. Display batching preserves materials, normals, UVs, bounds and triangles, and centers the shared display parent only. Existing M City/Artform models retain their original display structure.

Caption and interaction controls sit outside the canvas so small-screen roofs and podiums remain visible. Existing demand rendering, coarse-pointer resolution limits, touch scrolling/zoom, keyboard controls and context recovery continue to apply. Device testing is browser viewport/touch emulation; no physical Duo, Safari27.1 or hardware thermal claim is made.
