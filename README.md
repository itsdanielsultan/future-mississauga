# Future Mississauga

An independent visual atlas by Daniel Sultan: original 4K pictures, native 4:5 portrait images, a research register, and an interactive city model with existing GO rail corridors, the Mississauga Transitway and the Hazel McCallion Line. This is the Visual Polish edition of 26 September 2026: 24 native 3240 × 4050 ray-traced portraits, refreshed wide renders, repaired coastal water and Port Credit docks, consistent navigation, improved media controls and a map-first independent subway exploration.

The website is entirely static. It requires no Sites or OpenAI service, account, server API, application database, or secret. Three.js, meshoptimizer and Media Chrome 4.19.2 are included locally with their upstream notices. Bricolage Grotesque, Lato and the retained DM Sans fallback fonts are bundled under `public/vendor/fonts/`, including the official Google Fonts source record and SIL Open Font License notices; font rendering makes no external request. The 33 original city-gallery PNG downloads are hosted in this repository's `citywide-accuracy-images-2026-10-17` GitHub Release. Their unchanged full-resolution bytes were independently downloaded and SHA-256 verified; the proof is `public/data/original-image-release-integrity.json`. They are not recompressed. Displayed model pictures use separate PNG previews at exactly half the width and height (1920 pixels wide), under `public/gallery/previews/`. Download Image links point to the untouched 3840-pixel masters. The picture index records both versions and their hashes.

The waterfront 3D context uses bounded display water in Clarkson, Lakeview and the city overview. Lakeview keeps a 400 m coastal band with the full mapped pier and breakwater surrounded by water. These are presentation extents; mapped shoreline, source water level, terrain, roads, buildings and camera controls are retained. The public geometry record is `public/downloads/Waterfront-viewer-water-extents.json`.

The Clarkson model also includes source-mapped mainland linking its original district crop to Harding Waterfront Estate, with complete supported existing building components from the City source data. No source building was reshaped or moved. The public source record is `public/downloads/Clarkson-mainland-context-repair.json`.

The October 17 model update adds a separately loaded Churchill Meadows district, the reference-derived Winding Trail exterior and 228 Queen Street South frontage, a public coverage review, and two approved Gala Gateway render views. These are qualified approximations. The earlier wide pictures, portrait set and atlas PDF have not been regenerated by this model update.

## View locally

With Node 22 or newer, run `npm run dev` and open the printed local URL. No dependency installation is required. Opening the HTML directly through `file://` may prevent the browser from fetching the model files.

Run `npm run check` to prepare a temporary publication tree and verify HTML and Markdown links, local stylesheet/font dependencies, media hashes, original-download metadata against the separate public byte proof, publication size and excluded private artifacts. `npm run build` prepares and validates the same publication tree in `dist/`; it preserves the complete `public/` source. `npm run preview` serves that built folder. For a project-path check, use `node scripts/serve.mjs --site dist --base /future-mississauga/`.

Publication preparation removes whitespace from a reviewed subset of JSON files and recompresses only the IDAT stream of pinned legacy preview PNGs when smaller. The build independently checks every decoded pixel, filtered scanline and non-IDAT chunk against the untouched original. It preserves numeric JSON tokens, source dates, source/native-original records, historical upload proofs, all asset paths, and release-download masters. Legacy PNG URLs serve lossless derivatives in `dist/`; their current hashes and the distinct original hashes/recovery paths are in `data/publication-derivatives.json`, linked from Sources. Those pinned recovery URLs are locators, not a claim that this local build fetched or reverified remote originals. `public/` remains the source edition and may exceed the publication cap; only the fully validated `dist/` tree is eligible for a later approved publication. Both the strict 1 GB total cap and 100 MB per-file cap remain unchanged.

## GitHub Pages

This repository uses **branch deployment**. `main` retains the public source, provenance and build/preview tools. After explicit publication approval, the separate `gh-pages` branch must receive only the validated contents of `dist/`, at its root, with `.nojekyll`. Do not copy `public/` directly: it preserves original encoding bytes and exceeds the publication limit. Configure Pages to deploy from `gh-pages`, folder `/`. The initial static branch has no parent; subsequent updates are ordinary fast-forward commits. Unchanged image and model blobs remain shared Git objects across both branches.

This setup uses ordinary repository permission and adds no active Actions workflow. `docs/github-actions-example.yml` is an optional future example, outside `.github/workflows`; it does not execute. No extra workflow permission is needed for the current site. Repository creation, pushing and optional custom-domain setup are separate deliberate actions.

Application and preview URLs are relative. Full-resolution city-gallery downloads use the project GitHub Release. The 24 native 3240 × 4050 portrait masters and 24 lossless half-size 1620 × 2025 display versions are individual PNG assets in this repository's `high-resolution-images-block-nine-2026-10-03` GitHub Release. Their SHA-256 digests and independently verified public bytes are recorded in `public/data/social-pictures.json` and `public/data/portrait-release-integrity.json`. This keeps the Pages site below its hosting-size limit while retaining the original PNG bytes. No model archives are distributed with the image release.

The intended primary address is `https://futuremississauga.com/`, with `futuremississauga.ca` redirecting to `.com` while preserving paths and queries. `https://itsdanielsultan.github.io/future-mississauga/` remains the publishing fallback. Domain ownership, DNS, redirects and HTTPS must be verified separately before claiming the custom addresses are live. Configure only the `.com` primary in `public/CNAME` and GitHub Pages; the `.ca` redirect is a separate hosting/DNS task. The repository contains no DNS credentials.

The guarded exporter defaults publication metadata to the GitHub project address. After domain ownership is confirmed, re-export with `--site-origin https://futuremississauga.com/` before configuring the custom domain. Canonical links, social preview metadata, robots and sitemap follow the selected origin; research links remain unchanged.

The exporter enforces a conservative published-size limit below 1,000,000,000 bytes and a per-file limit below 100,000,000 bytes. Native Blender 5.2 scenes and original municipal research inputs remain in the current local source edition and are not published here. Selected studies have individual previews and GLB download controls at `model.html`, with their credits and limitations. Artform downloads preserve the exact accepted GLB; M City downloads are the documented registered web derivatives. The interactive viewer also transfers display geometry to the browser; this is not a copy-protection mechanism.

Official guidance: [Pages limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits), [Git file-size limits](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github), [Pages publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Model meaning

The subway page features the original TTC RTES Exhibit ES-15 as historical evidence, with its screened-out status retained. Its separate illustrative 3D corridor extends into Toronto using the City’s 2025 native building massing and topographic context through Sherway to Kipling. The dataset date, source attribution, ground registration and limitations are in `public/data/subway-toronto-context.json`. This source-date context is not an approved subway alignment or a survey of every current building.

The explorer combines reviewed municipal building geometry, documented replacement models, context, landscape and transit. A standalone building GLB does not contain that complete layered assembly. The current reviewed/reconciled models are the recommended building exports. Untouched municipal source snapshots are provenance material and must not be presented as the current assembled model.

GO stays green, the Transitway blue and HML gold. These are unlit route guides, separate from grey physical tracks. They follow the physical display profiles and use normal scene depth, so buildings, roofs, bridges and ground hide obstructed sections. They are not surveyed engineering profiles. Incomplete second-track mapping and the HML turnout reconstruction retain explicit schematic labels. The current research and model guides explain the remaining building, landscape and transit uncertainties.
